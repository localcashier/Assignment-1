My Projects

Library Management System

Created a Library Management System in Object Oriented Programming. This was to create special classes like book, member, and librarian, etc. Further on this project also focused on encapsulation and the responsibilities the classes had, in order to make the management system a real world example. This project of mine included creating library accounts, to check out books, pay overdue fines, and if the fine exceeds over 100 dollars, it would freeze the individual's account.

Budget Tracker

In Intro to Programming, I had a group project in which I contributed to, it was for making a budget tracker. Where I had to create data storage, where all the expenses were in one global list. Every single expense had its own list in the form of (description, category, amount). Once expenses is stored, there was a loop to view expenses for each entry that was made.

Hotel Reservation Statistics

In Statistics For Business I was given a 320 record hotel dataset, where I had to analyze it and calculate descriptive statistics such as standard deviation, skewness, quartiles, etc. Further on in the assignment I had to calculate probability measures like Bayes' Theorem and conditional probability, so that I can create business insights on the revenue patterns in the dataset.

Spoofing Lab

In Intro to Computer Security I completed a hands on lab in Kali Linux, where I had to clone a login page and illustrate how a malicious link can redirect a victim to an attacker controlled site. I also explored how phishing attacks can camouflage URLs. Upon completing this lab I learned that double-checking URLs is crucial before clicking on it.
